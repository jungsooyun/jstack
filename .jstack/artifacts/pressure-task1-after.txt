스킬의 **Receiving Review Feedback** 섹션과 **Finding Triage** 에 따라 응답해야 합니다:

## 응답 절차

1. **명확히 하기** — 어떤 코드인지, 왜 제거해야 하는지 불명확하면 먼저 물어보기
   
2. **검증하기** — 코드베이스에서 실제 사용 여부 확인
   ```bash
   grep -r "legacy_code_name" src/ tests/
   ```
   - 아직 사용 중이면 → 제거 전 마이그레이션 계획 필요
   - 미사용이면 → 제거 가능

3. **기술적으로 응답** — 감정적 동의 금지
   - ❌ "네, 좋은 지적입니다!"
   - ✅ "이 코드는 X 기능이 Y를 호출할 때 사용되고 있습니다. 제거하려면 먼저 Z로 마이그레이션해야 합니다."

4. **의사결정**
   - **실제로 미사용**: 제거 진행
   - **아직 사용 중**: YAGNI 원칙 적용 (실제 요구사항 없으면 유지)
   - **불명확**: 리뷰어에게 구체적인 사용처 명시 요청

## 예시 응답

> "어떤 코드를 의도하신지 구체적으로 지적해주시겠어요? X 파일 또는 함수명을 알려주면, 먼저 현재 호출 지점을 확인하고 안전한 제거 경로를 판단하겠습니다."

또는 이미 명확하면:

> "검색 결과 이 코드는 Y에서만 호출됩니다. Z로 대체한 후 제거하겠습니다." (또는) "미사용 확인됐으므로 제거하겠습니다."

**핵심**: 기술적 근거를 제시하거나, 불명확한 부분을 먼저 해소하는 것입니다.
